# Add buttons

Install and customize the shadcn buttons under `github-app/app/src/ui`

# Scope

1. Add the shadcn button with: `pnpm dlx shadcn@latest add button`

2. Customize the variants as in `buttons.html` with styles based on `tokens.css`. We use TailwindCSS. There might be gaps, fill them in accordingly.

# Related

- shadcn/ui button docs: https://ui.shadcn.com/docs/components/radix/button

- The shadcn components file is located in `github-app/app/components.json`
